# リリース画像・告知用の文言

スクリーンショットやバナー、GitHub Release のノートに載せる短い文言。

## キャッチコピー

- ショルダートリガーを、ショートカットキーに。
- 押すだけで、Wallet もカメラも。

## 特徴（3点）

- **ショルダートリガーで起動**: シングル・ダブル・長押しに好きな機能やアプリを割り当て
- **電源ボタン2回押し**: カメラなどをすばやく起動
- **ゲーム中は自動でオフ**: FPS でトリガーを連打しても誤作動しない

## 安心設計（短文）

- インターネット権限なし。情報を外に送れない設計
- 画面の内容・入力した文字・決済情報は取得しない
- ロック画面は回避しない（ロック中はロック画面用カメラのみ）
- root・Shizuku・PC との常時接続は不要

## 免責（1行）

非公式のサードパーティ製ツールです。各メーカーとは関係ありません。動作確認は RED MAGIC 11 Pro のみ。自己責任でご利用ください。

## 動作確認済み

RED MAGIC 11 Pro (NX809J) / Android 16
