# TriggerDeck

ゲーミングスマホのショルダートリガーと電源ボタンに、好きな機能やアプリを割り当てる Android アプリです。
左トリガーを2回押して Google Wallet、電源ボタンを2回押してカメラ、といった操作ができます。

> **非公式のサードパーティ製ツールです。** 各メーカーとは関係ありません。詳しくは [免責事項](#免責事項) をご覧ください。

## 動作確認済みの機種

| 機種 | OS |
| --- | --- |
| RED MAGIC 11 Pro (NX809J) | Android 16 |

上記以外の機種では動作しない、または想定外の動作をする可能性があります。対応機種は利用者の方からのフィードバックをもとに広げていく予定です。

## できること

### ショルダートリガー（左右）

シングル・ダブル・長押しのそれぞれに、次の機能を割り当てられます。

- Google Wallet / カメラ / 任意のアプリ
- ライトの切り替え / スクリーンショット / 音楽の再生・一時停止
- 通知パネル / クイック設定 / 最近のアプリ / ホーム / 戻る / 画面ロック

### 電源ボタン

2回押しに同じ機能を割り当てられます。

### ゲーム中の誤作動防止

- ゲームアプリが前面にあるときは、ショルダートリガーの割り当てを自動で無効にします。トリガーの入力はそのままゲームに届きます
- **ホワイトリスト**: ゲームと判定されるアプリでも、ショルダートリガーを常に使えるようにできます
- **ブラックリスト**: ゲームとして判定されないアプリでも、ショルダートリガーを無効にできます
- 判定の優先順位は「ホワイトリスト → ブラックリスト → ゲームの自動判定」です。同じアプリを両方に登録することはできません
- 同じアプリを短時間に何度も起動しないよう、連打を防ぎます

### 初期設定の割り当て

| 操作 | 機能 |
| --- | --- |
| 左トリガーのダブル | Google Wallet |
| 電源ボタンの2回押し | カメラ |
| その他 | なし |

## 安心設計

- **インターネット権限なし**: 情報を端末の外に送信できない作りです
- **必要最小限の情報だけを取得**: 取得するのはトリガーのキー入力と、前面にあるアプリの名前だけです。画面の内容・入力した文字・決済情報は取得しません
- **ロックを回避しない**: ロック中に起動できるのはロック画面用のカメラだけです。それ以外のアプリはロック解除が必要です
- **決済に関与しない**: Google Wallet を起動するだけで、カード情報や決済には一切触れません
- **root・Shizuku・PC との常時接続は不要**: 通常のアプリとしてインストールするだけで使えます
- **広告・解析ツールなし**

詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。

## インストール

1. [Releases](../../releases) から最新の APK をダウンロードします
2. ダウンロードした APK を開いてインストールします（「提供元不明のアプリ」の許可を求められたら許可してください）

## 初期設定

アプリを開くと「はじめに設定してください」が表示されます。

1. **ユーザー補助サービスを有効にする**: 「設定を開く」から TriggerDeck を選び、オンにします。トリガーの検出に必要です
2. **電池の最適化を解除する**: バックグラウンドで停止されないようにします

あわせて、端末の設定で本アプリの「自動起動」と「バックグラウンド実行」を許可しておくと安定します（アプリ内の「詳細設定 > アプリ情報」から開けます）。

## 使い方

### 割り当てを変える

ホーム画面の「割り当て」で操作をタップし、「機能」または「アプリ」から選びます。アプリは検索して選べます。

### ホワイトリスト・ブラックリストを編集する

「ゲーム中の誤作動防止」の各リストで「アプリを選択」をタップすると、アプリ一覧が開きます。チェックを付け外ししてまとめて選び、「完了」で確定します。登録済みのアプリは最初からチェックが付いています。

### 判定時間を調整する

「判定時間」で、次の時間をミリ秒単位で調整できます。

| 項目 | 既定 | 目安 |
| --- | --- | --- |
| 電源ボタンの2回押し | 400ms | 誤作動するときは短く、反応しにくいときは長く |
| トリガーのダブルタップ | 300ms | ダブルに割り当てがあると、シングルはこの時間だけ遅れて実行されます |
| トリガーの長押し | 500ms | |

### 電源ボタンの2回押しについて

- 画面が点いた状態で素早く2回押すと実行します
- 画面が消えているときは、1回押して点灯してから2回押してください
- 端末の「電源ボタンを2回押してカメラを起動」機能がオンだと二重に起動します。本アプリを使う場合はオフにしてください

## 困ったときは

| 症状 | 対処 |
| --- | --- |
| 急に反応しなくなった | アプリの強制停止や、端末のクリーンアップ機能でアプリが停止されると、Android の仕様でユーザー補助がオフになります。ユーザー補助を再度オンにし、クリーンアップの対象から本アプリを外してください |
| 再起動後に反応しない | 電池の最適化の解除と、自動起動の許可を確認してください |
| ゲーム中にトリガーで機能が動いてしまう | そのゲームを「除外するアプリ（ブラックリスト）」に追加してください |
| 特定のアプリでトリガーが動かない | ゲームとして判定されている可能性があります。「常に有効にするアプリ（ホワイトリスト）」に追加してください。GameSpace でトリガーを設定しているゲームでは、GameSpace の動作と同時に実行される場合があります |
| トリガーを押しても反応しない | 右上の「診断」で、トリガーを押したときにキーが表示されるか確認してください。表示されない場合は、Issues でお知らせください |
